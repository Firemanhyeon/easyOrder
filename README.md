# 🍽️ easyOrder  
> 음식점 테이블에 부착된 QR을 스캔해 고객이 직접 주문 및 결제할 수 있는 **B2B 웹 테이블 오더 시스템**

---

## 📖 프로젝트 개요  

최근 음식점들은 테이블마다 태블릿 주문기나 결제용 포스기를 설치하는 경우가 많습니다.
하지만 이러한 방식은 장비 비용, 유지보수 인력, 설치 공간 등에서 많은 낭비가 발생합니다.

저는 이 비효율적인 구조를 개선하고자
‘테이블에는 QR 하나만 남기고, 나머지는 웹으로 처리할 수는 없을까?’
라는 생각으로 easyOrder 프로젝트를 시작했습니다.

고객은 QR을 스캔하여 메뉴 확인 → 주문 → 결제까지 한 번에 처리할 수 있습니다

이 프로젝트의 목표는 물리적인 장비 없이도 동일한 사용자 경험을 제공하고,
소규모 음식점도 쉽게 디지털 주문 시스템을 도입할 수 있도록 하는 것입니다.

## ⚖️ 비슷한 서비스와의 차이점  

| 항목 | 기존 테이블오더 서비스 | easyOrder |
|------|------------------------|------------|
| **운영 대상** | 프랜차이즈 중심 | 개인 음식점 / 소상공인 대상 |
| **설치 방식** | 앱 설치 필요 | QR 기반 웹 접근 |
| **결제 구조** | PG 통합 (비용 높음) | Toss Payments API 직접 연동 |
| **주문 흐름** | 관리자 수동 확인 | 주문 완료 시 서버에 즉시 반영 및 주문 내역 갱신 |
| **관리 기능** | 단순 주문 내역 | 매출 통계 확인 (추후) |
| **아키텍처 구조** | Monolithic | 모듈화된 Monolithic 구조 (MSA 전환을 고려한 설계) |

## 🧩 주요 기능  

### 💡 고객 (테이블) 화면  
- QR 코드 스캔 시 매장/테이블 자동 인식  
- 메뉴 조회 및 장바구니 담기  
- Toss 결제 위젯을 통한 카드결제  
- 결제 성공/실패 알림 (Alert 기반)  

### 🧑‍🍳 관리자 화면  
- 메뉴/카테고리 CRUD  
- 매출 현황 및 결제 내역 조회(추후)  
- QR 코드 자동 생성 및 테이블 관리
